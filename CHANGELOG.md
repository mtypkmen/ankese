# Changelog

## 0.1.0

First public version.

- Accounts: email verification, password reset, brute-force protection, scrypt hashing
- Catalog: 10 categories, 32 cities (Albania and Kosovo), companies, company suggestions
- Complaint flow with moderation before publishing and an automatic pre-screening pipeline
- Admin panel with TOTP 2FA, queues, blocklist editor, user management and takedown/contact requests
- Public pages: home, companies, categories, cities, complaint pages, search, legal pages
- Dynamic sitemap with `hreflang`, strict CSP and security headers
- Encrypted daily backup script, deploy script, example nginx/systemd configuration
- Albanian and English interface
