# Code of Conduct

We want this project to be a welcoming, respectful place for everyone.

**Expected behaviour:** be kind and constructive, assume good intent, give and accept feedback gracefully, and focus on
what is best for the project and its users.

**Unacceptable behaviour:** harassment, insults, discrimination, personal attacks, publishing someone's private
information, and anything that would be inappropriate in a professional setting.

Maintainers may edit or remove comments, commits and issues that do not follow this code and may block contributors
who repeatedly violate it. To report a problem, write to **info@ankese.com**. Reports are handled privately.

This is a short statement of intent inspired by the Contributor Covenant.
